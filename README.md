## Description

Shields are extremely useful to have, but after awhile it gets really annoying to have to loose almost 1/4 of the screen. This addon is here to solve this issue!

By shrinking the shield base texture (not including the handle, its still the same size) by a couple pixels, the shield now looks significantly smaller and takes up less space! The first person view of the shield has also been shifted down even further.
